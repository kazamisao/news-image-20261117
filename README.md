A one-page broadsheet of the world news of Tuesday, 17 November 2026, drawn in code with Pillow: the Kerch Bridge strike as the hero story, plus the Hormuz tanker attacks, Trump in Manila, Nvidia's first post-Huang earnings, the DR Congo Ebola outbreak, and an "Also today" strip on Bahrain and the JPMorgan banking bug. `render.py` draws the image at 3x and downscales it to `news.png`; `main.py` (stdlib only) copies it to the output path, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
